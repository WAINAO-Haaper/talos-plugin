# Page Override: 收件箱（inbox）

> 覆盖 `../MASTER.md` 的通用规则。本页定位：**分诊台（triage）**——
> 用户进来要回答三个问题：积压有多老？主要是什么主题？先处理哪批？
> 版式与组件围绕这三个问题组织，不用通用的「数字卡 + 列表」骨架。

## 首屏骨架（覆盖 MASTER 的 Bento Grid 顺序）

1. **Hero**：标题 + 三项统计（待处理 / 主题包 / 最近进入）+ 主操作（开始归档）
   —— 统计只出现在这里，下方模块**禁止重复**同一数字。
2. **消化台（分诊核心区，6/6 等宽）**：
   - 左半 **积压年龄分布**（stacked bar）：0–3d / 4–7d / 8–14d / >14d 四桶，
     回答「这批东西有多老」。最老桶决定整页警告级别。
   - 右半 **主题分诊**：主题聚类卡按计数降序，每张卡底部放与最大值同 Scale
     的比例条，副标题直接标出优先处理的最大主题包，回答「先处理哪批」。
3. **最近进入**：列表退到第三层，以两列紧凑入口呈现；仅用于打开原文件，
   不承担统计职责。

## 组件规格

### 积压年龄分布（.age-dist）
- 单条 stacked bar，段宽 = 桶计数 / 总数；段色用语义状态色：
  - 0–3d → `--talos-status-info`（新鲜，中性）
  - 4–7d → `--talos-status-ok`（正常周转）
  - 8–14d → `--talos-status-warn`（开始积压）
  - >14d → `--talos-status-danger`（超龄，最高优先处理）
- 每段 ≥ 2px 最小宽度（计数为 1 时也可见）；计数为 0 的桶不占段、不出现在图例。
- 图例：色点 + 桶名 + 计数，**颜色 + 文字双编码**（a11y 红线）。
- 总数为 0 时整个模块不渲染（收件箱已清空由 hero 的 good 态表达）。

### 主题聚类卡（.cluster-card 增强）
- 保留现有卡结构（名称 / 大数字 / 提示），**新增**：
  - 底部比例条 `.cluster-bar`：track 用 `--talos-surface-2`，fill 宽 = count / max(count)；
  - 占比文字 `xx%`，放提示行右侧；
  - 「其他」类（需人工判断）fill 用 `--talos-status-warn`，其余用 `--talos-status-info`。

## 反模式（本页禁止）

- ❌ 同一统计在首屏出现两次（原「消化台 MetricGrid 重复 hero 数字」已移除）
- ❌ 仅靠颜色区分年龄段（必须有桶名 + 计数文字）
- ❌ 年龄分布用饼图（4 桶堆叠条在窄面板下更稳，且与 dashboard 密度一致）

## 动效

- 段宽/条宽变化走 `transition: width var(--talos-duration) var(--talos-ease)`；
- `prefers-reduced-motion` 下无过渡（继承全局规则）。
