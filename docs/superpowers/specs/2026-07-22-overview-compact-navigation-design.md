# 总览页紧凑浮层导航设计

日期：2026-07-22

## 目标

让总览页导航与其他 TALOS 页面保持同一套呼出/隐藏交互，在释放主内容横向空间的同时保留全部十二个导航入口。

## 交互设计

- 桌面静止态使用 72px 图标导航轨，只显示导航图标。
- 鼠标悬停或键盘焦点进入导航时，以 296px 浮层展开，显示分组标题、页面名称和状态数字。
- 鼠标与键盘焦点离开后自动恢复 72px，不改变主内容的起点和宽度。
- 1080px 以下展开宽度使用现有 260px 规则；760px 以下静止态使用现有 54px 图标轨。
- 不新增折叠按钮，不持久化展开状态，不改变页面切换、统计或审批功能。

## 实现边界

- 复用 `styles.quyuan-shell.css` 中详情页已有的紧凑导航规则，将导航壳层规则覆盖到总览页。
- 详情页和屈原页的主内容 padding、高度与滚动专属规则保持原样。
- 删除总览页旧的横向导航窄屏特例所产生的冲突，使所有页面共享同一套 72/54px 导航轨。

## 可访问性与动效

- 保留 `:focus-within` 展开，键盘用户可呼出完整导航。
- 保留导航项的 Enter/Space 激活行为和 Tab 顺序。
- 导航宽度过渡沿用现有 180ms；系统开启减少动态效果时取消该宽度过渡。

## 验证

- 先增加结构回归测试，证明总览页不再被排除，并验证主内容专属规则未扩大作用域。
- 在桌面、中等和窄窗口检查静止/展开尺寸、主内容稳定性、导航完整性及横向溢出。
- 运行完整测试、selftest、lint 和生产构建。
- 同步前备份 Obsidian 已安装的三个产物；同步后逐文件校验一致。
